場からの許可=全体最適($G$)、全体への納得・許可=個別最適($L$)として。
差分：$\Delta=G-L$ 、許容判定：$w|\Delta|<\epsilon$ としたとき、全体許可される癖の判定：$w_i|\delta_i|<0.5$ となる。
このときの条件として：
- 影響の小さい個人差は残し、全体を壊す差だけ調整する / 接続点
- 個別最適を、全体が壊れない範囲で同時に許可すること
- 全体へ接続した状態で、自分の差分を維持できること

そうなるとこいつらも定義できるっぽくてな↓
全体が個人を許可する条件：$$w^{(G)}_i|\delta_i|<\epsilon_G$$
個人がその状態に納得できる条件：$$w^{(L)}_i|\delta_i|<\epsilon_L$$
この両方を満たすことで、全体最適と個別最適の接続可能領域ってのが成立する。

さっきのストレスの結果が正にこれでさw 「全体許可は下りてるのに自己許可が閉じない」 or 「全体へ合わせ続けた結果、自己許可できる領域が消える」ってのが言える気がするw
全体の制約を個人の許容範囲へ翻訳し、個人の差分を全体への影響へ翻訳する双方向の変換器

```c
		Input -> "$delta_z"
		Weight -> "$abln2"
		Memory -> "tau"
	);	
	Field.state += ( Port(x) - Field.state / tau ) * dt;
	if (Port(x) in Field.range(-0.5,0.5)) {
		accept.Port(x);
		continue_action;
		return 0;
		
	} else if (Port(x) == -0.5 || Port(x) == 0.5) {
		transition.Port(x);
		continue_action;
		return 0;
		
	} else {
		reject.Port(x);
		return 1;
	}
}
```
