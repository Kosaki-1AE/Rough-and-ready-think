#Mine研究 
set($B$ 決定) -> hit($S$ 確定) ->  shoot($L$ 決定) -> pop(vector -> 責任の矢($N$ 導出) -> scalar($\ln$ 導入)) -> off($\log$ の解除)

まずはこれ：
- $B_{self}$、$B_{you}$
- $S_{self}=\ln B_{self}$、$S_{you}=\ln B_{you}$
- $|B_{self}-B_{you}|=B_{max}-B_{min}$
- $|S_{self}-S_{you}|=S_{max}-S_{min}=|\ln\frac{B_{self}}{B_{you}}|$

そんでこれ：
- $\Delta B=|B_{self}-B_{you}|=B_{max}-B_{min}$
- $\Delta B_{\wedge}=min(B_{self},B_{you})$
- $\Delta S=|S_{self}-S_{you}|=S_{max}-S_{min}=|\ln\frac{B_{self}}{B_{you}}|$
- $\Delta L=\ln B_{self}\land\ln B_{you}=min(\ln B_{self},\ln B_{you})=\ln min(B_{self},B_{you})=\ln\Delta B_{\wedge}$
- $\Delta N=\Delta B_{\wedge}^{\Delta L}=\Delta B_{\wedge}^{\ln\Delta B_{\wedge}}$

となるとおそらくsetが$\Delta B$ 、hitは$\Delta S$ 、shootは$\Delta L$、popは$\Delta N$ってことになる気がするのよね

set -> hit ->  shoot -> pop(vector -> 責任の矢 -> scalar) -> off
1. set：基準を決める / G
2. hit：関係距離を見て同期に合わせる / B
3. shoot：方向を与える / 責任の付与 / M
4. pop：
	1. vector：(自分は)「どれだけ・どこへ？」を決定する / C$_1$-C$_2$
	2. 責任の矢：自分が関わることによって与える影響の大きさ / Q
	3. scalar：(関係距離が)「どれだけ？」かを観測する / S
5. off：責任の解除、scalarに戻す。setへ〜 / D

顕在化：scalar -> vector、回収：vector -> scalar

多分これを組み合わせんとマズイと思ってな
G → B －(GL)→ M → C$_1$ －(DO)→ C$_2$ → Q －(BO)→ S → D －(CM)→ G
