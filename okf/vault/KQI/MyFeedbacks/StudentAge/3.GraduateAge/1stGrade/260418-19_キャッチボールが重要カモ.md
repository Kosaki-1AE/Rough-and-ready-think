言語：言葉の抽象度(一般⇔特異)、意味領域の差、文脈の流れ(時間的遷移)
音楽：音の明暗・強弱、音の複雑さ・ノイズ性、時間的遷移・揺れ
動画：色の明暗・強弱、色の構造(複雑さやノイズ)、動き(時間的遷移)

共通の軸
- X = 概念の抽象度
- Y = 感情方向（ポジ/ネガ）
- Z = 行動/状態方向
位置 = 意味
色   = 明暗
大きさ = 強弱
広がり = 複雑さ
軌跡 = 文脈

音楽の場合：
- 位置 = 音の種類
- 色   = 明るさ
- 強さ = 音量
- 軌跡 = フレーズ

動画の場合：
- 位置 = シーン種類
- 色   = 明るさ
- 強さ = 動き
- 軌跡 = 編集

言語の場合：
- 位置 = 意味
- 色   = 感情（明暗）
- 強さ = 強調
- 軌跡 = 文脈

意味空間（3D）＋ 状態レイヤー（明暗・強弱・複雑さ）＋ 時間（軌跡）
