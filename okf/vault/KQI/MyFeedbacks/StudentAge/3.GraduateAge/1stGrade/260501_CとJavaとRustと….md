#パソコン/Coding 
レジスタとスタックっていう違いがあるっぽいなぁ…。レジスタはメモリに直で書き込む、スタックは順番で管理するってだけらしい。
スタック＝時間順の意味保存、レジスタ＝空間配置の意味保存、らしいです。

C言語：.c → .i → .s → .o → 実行ファイル
Jcva：.java → .class → JVM
Rust：.rs → MIR → LLVM IR → .o → 実行
