#パソコン/Coding 
プログラミングにおける「%」ってのが、剰余こと $mod$ と同じ意味になるんすけど、プログラム内においては「循環させられる環境」ってことになるんすよな。

基本プログラム言語、こっちが打ち込んだ数やら何やらが上限やら下限やらになるっていう仕様です。

- &(AND)：マスク処理
- |(OR)：フラグON
- ^(XOR)：比較でビット反転
- ~(NOT)：単独でビット反転

- PMOS：トランジスタの並列
- NMOS：トランジスタの直列

- NAND/NOR：PMOSとNMOSで勝手に構造として立ち上がる代物
- 1bitラッチ(RS-FF)：NAND 2個でできる「1bit記憶装置」で、Reset Set Flip-flopの略
- CLK：RS-FF が「いつでも書き換わる」という性質があるので、これを制御するための演算装置(D-FF)
- レジスタ：FF の集合体

古典コンピュータ：トランジスタ → NAND → FF → レジスタ → ALU → CPU

量子コンピュータ：量子ビット → 量子ゲート（H, X, CNOT） → 量子回路 → 測定


一旦まとめ。
量子コンピュータでやりたいのよなぁ…。というか上で定義したこと。オイラーの公式関連よね。
