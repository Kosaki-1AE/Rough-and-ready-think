@オペレーティングシステム特論：調べろ的なやつなんでな。先にこっちかなぁって。
- **シェル**：
V1(素朴な`sh`) → V2(`goto`/`if`/`chdir`追加) → V6(`newgrp`) → V7(Bourne Shellへ全面書き換え(`test`/`export`/`read`/`trap`))

- **デバッガ**：
V1(`db`) → V3(`cdb`初出(プレースホルダー)) → V6(`cdb`実用化) → V7(`adb`が`db`/`cdb`を統合置換)

- **Cコンパイラ**：
V1(`B`言語) → V2(`cc`初出(`B`置換)) → (以降変化なし)

- **Fortran**：
V1(`for`) → V2(`fc`に改名) → V6(`rc`(Ratfor)追加) → V7(`f77`が`fc`置換)

- **他言語処理系**：
V3(`sno`初出) → V5(`sno`をVIへ降格) → V6(`bc`初出、`yacc`をIへ昇格) → V7(`awk`/`m4`/`lex`新規参入)

- **テキスト整形**：
V1(`roff`) → V2(`nroff`追加) → V4(`troff`追加) → V5(`eqn`/`neqn`追加) → V7(`sed`初出)

- **検索/差分**：
V1(`find`) → V3(`find`消失、`proof`初出) → V4(`grep`初出、`diff`が`proof`置換) → V5(`find`復活、`tee`初出) → V6(`comm`/`file`追加) → V7(`diff3`追加)

- **アーカイブ**：
V1(`tap`(DECtape専用)) → V2(`mt`(magtape)追加) → V5(`tp`に統合) → V7(`tar`に統一)

- **暗号化**：
V3(`crypt`初出) → V4(消滅) → V6(ライブラリ関数として復活(III)) → V7(コマンドとして復活(I))

- **システム管理**：
V1〜V2(`mount`/`umount`/`boot`/`mkfs`/`check`/`df`/`acct`等が一般コマンド) → V3(Section VIII新設、ほぼ全部そこへ移動) → V6(`chown`もVIIIへ降格) → V7(「Administration」として正式確立)

- **ライブラリ(Section III)**：
V1(`atof`/`ctime`/`sin`/`log`等の基礎のみ) → V2(`nlist`/`qsort`/`hypot`追加) → V3(`compar`/`pow`追加) → V5(`alloc`/`floor`/`gamma`/`monitor`追加) → V6(`abort`/`abs`/`fmod`/`ptrace`/`getpid`追加)
