遷移順列生成 = 状態遷移の規約生成 = 構造形成条件
基準となる制約書類 = 不変量
- 上限 = 個性が消滅する最高制約
- 下限 = 構造が崩壊しない最低制約

重み = その要素を消したときに制約体系がどれだけ崩れるか
⇨ 「何を守るためにその差分が存在しているのか」を表す量なのかw

- 不変量 = 制約書
- 重み = その制約書を維持するための寄与率 = その制約が検証を何回生き残ったか
- 責任 = 制約崩壊時の影響度
- 沈殿 = 検証に耐えた回数
- 保険 = 制約崩壊時の回復能力

個性 → 比較(不変量上限) → 選択 → 差分生成(個性上限) → 検証(遊び/保険を残す) → 差分除去(個性下限) → 遷移順決定(不変量下限) → 構造 → 不変量 → 抽出 → 規格
