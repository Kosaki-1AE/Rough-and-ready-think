- 降り＝選択的、登り＝決定的。 崩れは深さで3分岐(GL→FM/DO→SCB/BO→CM)、立て直しは一本道(FM→SCB→CM)。非対称が本体
- GL/DO/BOは登りには存在せん。 参照の壊れ方＝降り専用の分岐器。登りに探すのは筋違い、で決着
- BOは浅層×高コスト。 深さ(CM層で直る)とコスト(擦り合わせが跳ねる)が別軸、の実例

- 降り：
参照を握った状態での照合 -> 参照が壊れうる -> GL/DO/BOが存在、しかも壊れる深さで分岐

- 登り：
参照を手放した状態での再構成 → 壊れる参照が無い → GL/DO/BOは定義できん → 一本道

- SCB＝滞在時間τが設定可能になる線
- GL：τ固定（私的・動かせん）／CM：τを他人が設定（社会構造）／SCB：自分でτを置ける唯一の層
- 訓練＝τを縮めて一点を二点に割り、間に判断を差し込む操作
- 一点は未訓練の既定値であって自然法則やない。割った点は戻らん

- ロボットもHiphopも「τを音楽に預ける」が共通前提（対立やなく包含）
- 変数はτの所有権やなくて許容偏差ε
  - ロボット：ε=0（グリッド着地が表現）
  - Hiphop：ε>0（εの置き方＝レイドバック等が表現）
- ズラせるのは預けてるから ＝ 壊れうるのは握ってるから（同型）

- 未訓練のε=0（素）と抑圧されたε=0（訓練後）は観測上同じで中身が別
- GL/CMの区別の身体版。抑圧版は保持コストを食い続ける
- 「止まってるだけで疲れる」感覚があればその証拠（浅層×高コスト＝BOと同軸構造）

- hiphop→ロボット：クランプ（射影）。一手・瞬間切替可能。ただし保持コスト継続
- ロボット→hiphop：再同期。位相ロックし直す過程。数小節かかる
- 崩すのは一瞬、建て直すのは過程
- →降り＝選択的・瞬間的／登り＝決定的・一本道・過程、の非対称の身体実装

- 操作としての切替（クランプ可能）と、状態としての復元（素のε=0）は別レイヤー
- 復元は原理的に不可能：割った点は戻らん
- 「戻る」やなくて「εを0に保持する技能を新しく建てる」が正しい定式化

1. 再同期時定数：ロボット→hiphopでグルーヴに乗るまで何小節か。練習で縮む変数は多分これ
2. ロボット専門（Hiphop未経験）の踊り手と抑圧版ロボットの見た目の区別。つかなければSCB遮蔽が効いてる証拠
3. Hiphopの上手さ＝εの置き方の解像度、として測れる
