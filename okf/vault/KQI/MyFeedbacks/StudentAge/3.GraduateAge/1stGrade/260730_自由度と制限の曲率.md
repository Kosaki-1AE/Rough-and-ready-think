	遷移

GL/DO/BO/CM 👈これだもんなぁ。
例としましては…
1 + 2 × 3 = 2 × 3 + 1より、2 × 3 -> +1 
	`×         ->  +
	`├─ 2       ├─ 1
	`├─ 3`

if x > 0 then print("Hello") より x > 0 -> then print("Hello")
	`if               -> then`
	`├─ x > 0       ├─ print("Hello")`

max(a, b + c)  より max(b + c) -> output(a)
	`max   -> output`
	`├─ b           ├─ a`
	`├─ c`
