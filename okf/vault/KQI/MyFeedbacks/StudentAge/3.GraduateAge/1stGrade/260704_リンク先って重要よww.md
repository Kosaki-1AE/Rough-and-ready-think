amd64 = x86_64 = 64bit PC向け
amd64：IntelでもAMDでも動くx64系Linux
- 32bit → 扱えるメモリが基本4GB付近まで、4バイトポインタ
- 64bit → 4GBを大きく超えてメモリを扱える、8バイトポインタ

x64に一番近いARMの“規格”：ARM64 / AArch64
x64ノートPCに一番近いARM機：Apple Silicon MacBook、Snapdragon X搭載Windowsノート
x64 Linux遊びに一番近いARM：ARM64 Linux / Raspberry Pi 5 / ARM Chromebook

- x64 Linux：普通のPCを自由にするやつ
- ARM64 Linux：小型機械・省電力PCを自由にするやつ
