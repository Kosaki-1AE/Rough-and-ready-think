歴史の流れと共に。
- &(AND)：マスク処理
- |(OR)：フラグON
- ^(XOR)：比較でビット反転
- ~(NOT)：単独でビット反転

- PMOS：トランジスタの並列
- NMOS：トランジスタの直列

- NAND/NOR：PMOSとNMOSで勝手に構造として立ち上がる代物
- 1bitラッチ(RS-FF)：NAND 2個でできる「1bit記憶装置」で、Reset Set Flip-flopの略
- CLK：RS-FF が「いつでも書き換わる」という性質があるので、これを制御するための演算装置(D-FF)
- レジスタ：FF の集合体

古典コンピュータ：トランジスタ → NAND → FF → レジスタ → ALU → CPU

量子コンピュータ：量子ビット → 量子ゲート（H, X, CNOT） → 量子回路 → 測定
