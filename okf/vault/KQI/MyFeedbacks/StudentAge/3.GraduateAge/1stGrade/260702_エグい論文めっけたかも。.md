あ、これだけ宣言しとくね。GL/DO/BO/CMの4つを主にするわ。GBMCの中で使うものもあるかもだけどw
- GL ⇔ 基準化状態：拍・姿勢・ジャンルの基準に乗っている状態
- DO ⇔ 差分生成状態：基準からズラし，個性や表現が発生する状態
- BO ⇔ 過負荷状態：ズラしや運動負荷が大きくなり，余裕が失われる状態
- CM ⇔ 構造回収状態：動作や音楽構造へ戻り，まとまりを作る状態

これで言えるようになったことがありそうでな：
![[gbmc_flactal3.png]]
- GL：G→B→M = 基準に乗る：拍・型・基準に入る
- DO：G→S→Q = 差分を出す：ズラす・遊ぶ・個性を出す
- BO：D周り = 差分が詰まる：力む・詰まる・破綻する
- CM：D→C$_1$/C$_2$ = 差分を回収する：戻す・締める・余韻を作る

外界 = Music / Video / 環境

Q = 探索
D = 差分判断
C/C = 自分側の動作・信頼・自由度

俺の理論ね
興味 G → 候補分布 B → 比較 GL → 差分生成 DO → 検証 → 差分除去 BO → 遷移順決定 CM → 構造 → 行動 / 出力

一般向け
入力 → 候補生成 → 比較 → 差分生成 → 検証 → 差分除去 → 遷移順決定 → 出力

ダンス向け
音楽・動画入力 → 身体特徴量候補 → 基準との比較 → ズレ・個性の生成 → 破綻していないか検証 → 不要な差分を除去 → 次の動作への遷移順を決定 → 評価語 / 動作構造

本研究では，ダンス動作の遷移を解釈するために，
基準化 GL，差分生成 DO，過負荷処理 BO，構造回収 CM の4状態を補助的に用いる。

- GLは，動作が音楽やジャンルの基準に乗る状態である。
- DOは，基準からのズレや個性が生成される状態である。
- BOは，過剰な差分や力みが現れる状態である。
- CMは，生成された差分を次の動作や全体構造へ回収する状態である。

これっぽい：葉(leaf)の上、って地理的な意味
壁の向こう(個性・bracket-generating)で初めて「許された方向にしか動けない+コストがかかる」が発生する=これが劣リーマン
不変量領域=葉の上のリーマン(閉じ込め) → 壁(劣リーマンが特異化・一手が二手) → 個性領域=ちゃんとした劣リーマン

- 幾何学的制御 = 到達可能性(そこに行けるか)
- 劣リーマン = そのコスト(行くのにいくらかかるか)。つまり**制御+計量**。制御理論に距離を足しただけ
- ゲージ = 一周のズレ(ホロノミー)

コスト(計量)を、許された方向(分布)の上にだけ定義してるか、接空間全体に定義してるか
前者：ガチ劣リーマン、後者：リーマン + 制御制約
→ 多分後者にすると死んじゃうやんすか。まぁ前者に絞ることになるんでしょうね。
コストは分布方向にしか定義されてないから、分布から外れた方向(壁の手前で行きたくても行けない方向)は「コスト無限」じゃなくて「コスト未定義」として扱う 👈これが正解らしいねw

幾何学的制御理論の枠組みで記述し、コスト構造を劣リーマン計量として、経路依存性をホロノミー(アーベル近似)として扱う：順序が効かない範囲(ループ本数とか位相とか)は回路図で正しく書けてるけど、順序が結果を変える部分(個性の本体)はまだ回路図の外にいる

不変量って「どういう経路で来ても同じ葉ラベルになる」保存量だったよね。経路によらない=順番によらない=アーベル。
逆に個性は「どの順で操作したか」で変わる=非可換。だから個性が非可換性の産物、っていう昨日の計算結果((X1,X2)が個性軸を開いた)は、「個性=順序が効く=非アーベル」ってことを言ってる。

- 幾何学的制御にもアーベル/非アーベルがある(ベクトル場が可換に交換するか=Lie括弧がゼロか非ゼロか)
- 劣リーマンにもある(分布の括弧が閉じるか開くか)
- ゲージにもある(U(1)=アーベル、Yang–Mills=非アーベル)

Lie括弧がゼロ(可換・アーベル)⇔ 可積分 ⇔ 葉に閉じ込め ⇔ 不変量  
Lie括弧が非ゼロ(非可換・非アーベル)⇔ 括弧生成 ⇔ 葉を脱出 ⇔ 個性

変量=アーベル端、個性=非アーベル端、意味の壁=その軸の切り替わり点
