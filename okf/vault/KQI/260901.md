#パソコン/操作 
OneDrive管理下にしたときの差が分かってきたんで....書いとくことにしやす。
元々：Windows → C:\Users\kos04\Desktop

OneDrive接続
     ↓
OneDrive「Desktopも同期対象にするで」
     ↓
WindowsのDesktop参照先を書き換える
     ↓
何らかの理由で書き換えが正常完了しない
     ↓
レジストリ：%C:\Users\kos04%\Desktop   ← 壊れた値

さらにExplorer側にはOneDrive\Desktop の情報が一部残る

```python
$desktop = "$env:USERPROFILE\Desktop"

New-ItemProperty `
  -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders" `
  -Name "Desktop" `
  -Value "%USERPROFILE%\Desktop" `
  -PropertyType ExpandString `
  -Force
```
これの結果を：%C:\Users\kos04%\Desktop -> %USERPROFILE%\Desktop 変更しますとw
んでこれね
```python
New-ItemProperty `
  -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders" `
  -Name "Desktop" `
  -Value $desktop `
  -PropertyType String `
  -Force
```
これで実体として：C:\Users\kos04\Desktop 👈これを指すようにしますとw
設定直った？
```python
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders" |
Select-Object Desktop
```
結果としては：%USERPROFILE%\Desktop 👈これで完成と
んで再起&確認ーー。
```python
Stop-Process -Name explorer -Force
Start-Process explorer.exe
[Environment]::GetFolderPath("Desktop")
```
出力：C:\Users\kos04\Desktop 👈これでクリアという判定になりやすわ

消し方も書いておく：
- パワシェ：`Remove-Item -Recurse -Force .\`
- cmd：`rmdir /s /q Dancemotion`

こっから会話のキャッチボールについてのこととして見てほしいんだけどさぁ.....。
一回踏み込み入れるとするやんすか......これがバレーボールで言うところのトスに該当しましてw つまりは「アタック」のタイミング＝お笑いにおける「ツッコミ」に該当するってことになるのねw
んでこれがテンポゲーやんすかw 例えに出したバレーボールにおいてはw 
つまりここから言えるんが.....ツッコミにおけるタイミングってのには条件があってw 「バレーボール的に気持ち良いテンポ $\land$ テンポ的に100%確実に場に落ちる勢い」ってのが前提条件として言えると思われるのねw

んでこれが責任にも適応されるんだけどさぁ.....。踏み込んでからツッコミを出すときの重みってのが「責任」に該当するのね。
んでここでの「責任」ってのをモデル化したものを今の俺は構築済みでさぁ.....↓
- G → B －(GL)→ M → C$_1$ －(DO)→ C$_2$ → Q －(BO)→ S → D －(CM)→ G
- set(G) -> hit(B) ->  shoot(M) -> pop(vector(C$_1$ -> C$_2$) -> 責任の矢(Q) -> scalar(S)) -> off(D) -> set(G)....
- set(G) -> hit(B) - /GL >  shoot(M) -> pop(vector(C$_1$ - /DO > C$_2$) -> 責任の矢(Q) - /BO > scalar(S)) -> off(D) - /CM > set(G)....

んで大元の組み合わせはこれだったのね：
- hit(B) - /GL >  shoot(M) 👈これが1歩目の踏み出しね。相手の容量 × 行動で相手の力量が図れる
- 責任の矢(Q) - /BO > scalar(S) 👈これが遊びね
- off(D) - /CM > set(G) 👈責任を取るがここやね

あとはGPTに読ませますかw 今の俺にはちゃんと言語化できる自信がないんでなw

一応こうなるっぽいの：
set -> hit：相手/場に触れる -> shoot：踏み込む -> pop：方向を作る -> Q：ここで行く、と決める -> S：強度を決めて出す -> off：結果を受ける -> set：場を再構成する
