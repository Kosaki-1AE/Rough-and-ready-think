今寝てて急にアイデア降ってきたから勢いで描くぞい。記法これでいくとおもろいかも「#[@type→○○(使いたい要素の名前ね)]」って書いた結果が「#○○」っていう表記になるようにしたいw

結果としてこうなったら面白いっぽいww：
SOURCE：#[@type→Algorithm]

        ↓ parse
AST：TypeAnnotation("Algorithm")

        ↓ render

VIEW：#Algorithm

タグの基本構成これでいくわ：
- #[@type:Algorithm]
- #[@type Search := "探索処理"]
- #[@type Input => Output]

反映想定結果としては：
- #[@type:Algorithm]
- #[@type DFS := "深さ優先探索"]
- #[@type [[Graph]] => [[TraversalResult]]]

AST：
	TypeDeclaration(Algorithm)
	Definition
	├─ type: DFS
	└─ value: 深さ優先探索
	Transition
	├─ from: Graph
	└─ to: TraversalResult

Def：
- =：Identity（同一性）
- >：Direction（方向）
- :：Binding（束縛・型付け）
- :=：Binding + Identity
- =>：Identity + Direction
- >=：Direction + Identity(Reflexive)
- == ：Identity Query

ちなこれは入れたいかもw

定義       :=             =:
方向       :>             >:
