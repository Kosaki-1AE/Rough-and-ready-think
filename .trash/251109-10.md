#Mine研究 
参考文献は端折り、3.2も端折り。

今FreeBSDやってるやん、それで思ったことがあってさ。今んとこ何もないやん、でも色々アプリ入れていくとして、結局メモリの大きさ＝棚の大きさとか収納方法とかそういうものになるのよ、となると俺は「メモリの容量が一定の場合になった場合の最も効率良い収納方法はあるのか？」という問題に取り組めばよいってことになるのよね。

これがナップサック問題と同じことになるらしいの。なのでもっかい考え直しかな、前のアルゴリズムの授業の再演というか。なお今回は「意味圧縮付き」らしいです。

今回言いたい点：「行動を決めるのに十分な情報だけを残した状態」、意味圧縮 = (行動可能性) / (使用メモリ)

俺の好きなモノ＝Liminal Space

そう考えると俺がダンスの中に「ノイズ」を入れられるようになったってのも割と当たり前のことなのかもしれんな。
しかも俺の場合は「リミナル観測 → 内部保存 → 構造化  → ダンスに逆輸入」

俺の中でやってること⇩
- リミナルスペースを眺める（未意味データ）
- そのまま保存（評価しない）
- 内部で圧縮（雰囲気・感触・構造として）
- 必要なときに展開（ダンス・理論・表現に変換）

意味圧縮 = ラベルを貼らずに特徴量だけ保存
- 容量：脳・身体・時間
- アイテム：リミナルな体験
- 価値：未来で意味になる可能性
- 重さ：覚えるコスト

ノイズ = 圧縮された未意味データの展開

意味圧縮付きナップサック問題：将来的に意味を生成する可能性を持つ未評価データを、限られた容量の中で最大限保持する選択問題。通常ナップサック問題との差はこちら⇩

| 要素       | 明確(大元) | 未定義(俺の方)    | GBMC      |
| -------- | ------ | ----------- | --------- |
| 重さ       | 数値     | 記憶コスト・身体負荷  | Motion    |
| 価値       | 数値     | 未来に意味になる可能性 | Buffer    |
| 容量       | 数値     | 脳・時間・集中力    | Buffer    |
| 最適解      | 定義できる  | 未来依存        | Coherence |
| 何が候補になるか | 明示     | リミナル観測由来    | Genesys   |
⇨ 意味になる前には選んでないと成立しないっぽいのよね。

価値が未定義な状態のままBufferに保存し、Coherenceで後から意味を確定させるナップサック
