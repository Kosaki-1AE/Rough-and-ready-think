- **定義の壁 / DO**：条件によって確定する定義を壁とすることで、定義範囲の下限を確定する。

- Quality：保険分とPoolと空気感とを見て出していいかを判断する / 構造的復元
- Twist：一旦捻りを入れたものも出してみた / 情報流の担保
- **責任の壁 / BO**：自分が今いる場所などで、最終的な踏み込みとするために建てる壁(走り幅跳びの踏み込みのイメージね。実際これだとすら思うし)

- Depth：結局残されたPoolが何なのか確認するたーいむ / 部分的復元
- Output：どの出力結果になるか知らんが出します / 情報流の担保
