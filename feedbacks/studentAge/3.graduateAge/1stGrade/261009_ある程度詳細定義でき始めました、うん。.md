Bridging Kolmogorov Complexity and Deep Learning: Asymptotically Optimal Description Length Objectives for Transformers 👈俺の理論の架け橋になると思われ。

同一を定義すること＝開始点を決定することだから、一発目の照準さえ定まれば全て行けるのはあると思われ。
-> 基準点を一度確定すれば、以後の比較を局所的な状態遷移として処理できるのではないか？

1点で位置確定、2点目で軸・距離が確定(自由度が確定)、3点目で面・向きが確定 👈これアホ重要な可能性あるww

もし操作ことRで操作する分布ってのが3点で定義できるような分布やったら…www

基準点を確定したら、そこを中心に周囲を多方向から観測して、得られた情報を比較し、もう一度基準を更新して観測する。これを繰り返して整合させる

んで俺における「強制」：自分と周囲の双方に変更権限を持たせて、絶対的な時間制約の中で整合するように調整する

期限内に整合を成立させるため、変更する対象を自由に選択する
時間の上限と下限を決めることで、探索すべき操作を制限できる
時間範囲を設定できることと、その範囲内に必ず解が存在することは別

現在の関係が成立するように、自分と周囲の双方を変化させる
-> 時間の上限に到達した時点の状態を、その時点で確定した結果として扱う

絶対的目標達成 vs 分かり合えればそれでいい
-> 正解を求めるのではなく、異なる状態同士が共存できる関係を成立させる

整合性を数値で評価することと、その数値を最大化することは違う

0.03秒が下限、焦点の発見時間が上限ね。ここの間で「探索の結果として、何に着目すべきか」が確定するってことね。
-> 踏み込みの実行を時刻0として、受容が成立するまでの時間窓を定義できる

染み込ませる = 酵素として「分解した状態になる」なんだわ。

焦点とは、探索によって認識された関係性のうち、観測者が最も興味を持つ関係性を含む要素である。

内部状態を未確定のまま保持しても、次の遷移に必要な情報だけで整合を維持できる条件
-> (ダンスで気づいた、というか俺のスタイルを突き詰めた結果気づいたことだけどね)最小単位の時点で得られる質によって全てが決定される(というかあとは微分によって調整って感じか)、というか「最初にあった要素の方が粘性が強くなっていく」が正解かも。動かないことがめっちゃ重要で、「動かない状態＝粘性が増して影響力も向上する」ってことなのかなぁって。

動かせるけれど、時間とともに動きにくくなる。
-> 「動かなければ面倒くささ増す」なんよ

「動かないこと」と「他者を動かすこと」を別々の変数として定義できたら…
-> 「歴が長い要素ほど粘性が強くなる」ので「歴が長いやつを主から外した瞬間に全要素の粘性が基準値に戻る」なのよね。つまりは重力場ですw

命題：各要素の履歴が保存され、粘性が現在の主と履歴の関数として定義されるなら、主の解除によって履歴を失うことなく全要素の粘性を基準値へ戻せる

主の移譲は、旧主を足場として成立する

オブラートの区分だけどさぁ…
- 1枚目：観測対象を包む層
- 2枚目：拘束を解除・移譲する層

何を認識しているかと、何を基準として動けるかを別々に扱える。
しかも、2枚目で主を切り替えても、1枚目で得た情報や各要素の履歴を消す必要はない。

主の移譲を行っても、整合関係が維持される条件
-> 主の移譲の代わりとして出すのが「(積んできた責任を使った)踏み込み」なら俺としては凄い腑に落ちるのよねぇ

踏み込みは自分の責任を使って行うけど、成立するかどうかは自分と周囲の関係性で決まる

責任点は「存在した時間」を記録するのではなく、「その時間内に成立した観測・相互作用の履歴」を蓄積する
