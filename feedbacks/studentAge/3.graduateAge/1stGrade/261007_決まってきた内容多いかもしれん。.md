#Mine研究 
ダンスの動きを解析する -> 多分だけど選択肢の中での最頻で比較していくとある程度の遷移が見えるはず。
この遷移を「$F_t(\text{Straight},\text{Twist},\text{Jab})$」と置く。
対応表は以下の通りとする：
- $\text{Straight}$：強制的に遷移する / $b_3b_2=00/01$、$b_1b_0=10/11$
- $\text{Jab}$：迷うのを許可する(しかも場の支配がね) / $b_3b_2=10/11$、$b_1b_0=00/01$ 
- $\text{Twist}$：タイムスタンプが教えてくれる / $b_3b_2=10/11$、$b_1b_0=10/11$
- $\text{Observe}$：強制的に場を用意する / $b_3b_2=00/01$、$b_1b_0=00/01$
以下、これを「$F_t(\text{O},\text{S},\text{J},\text{T})$」とするのね。

中身としては $b_3b_2\times b_1b_0$ こと2bit $\times$ 2bit。全4bitになります。んでここに入ってくるのが16進数ですと。それぞれのラベルに左上から昇順に配布していきますと。この16進数ってのがHexに該当するのね。
なんだけどここで言いたいのが.....「Hexで中身まで確定したいわけではない」ってことなのね。
と言うことでここで定義しますのが「$R_t\in\mathcal R_t^{(h_t)}$」っていう代物ですわ。これがHexを入れる箱ね。

じゃあ、何を確定すれば十分なんや？ってことになるんで.....こういうのを定義しますと
-> 「$[R_t]_{\sim_t}$」 👈これが「現在の遷移に必要なところまで確定した状態」ってことになるのね。

これを変化させうる差がResponsibilityこと責任っていう定義にするともう都合が良いってことらしいのね。Responsibility = 出力・遷移を変えるのに必要な差

一旦まとめるとこう：4bit -> Hex -> $\mathcal R_t^{(h_t)}$ -> $[R_t]_{\sim_t}$ -> Responsibility

結果を変える「同値類間の遷移」だけ見ればよし 👈これをどうすりゃ表現できるんかっすよねぇマジで。

$R_t\in\mathcal R_t^{(h_t)}$ より、0, 1, 4, 5 / 2, 3, 6, 7 / 8, 9, c, d / a, b, e, f 👈こいつらがセットになるんだけどさ。
こいつらを対応させると、$\text{O}$, $\text{S}$, $\text{J}$, $\text{T}$ にそれぞれ対応します。緩急 / $\text{O}$, $\text{S}$、時間軸 / $\text{J}$, $\text{T}$ の区分になるのね。
だからこうも言えるんかな？：
- 緩急 / $\text{O}$, $\text{S}$：0, 1, 4, 5 / 2, 3, 6, 7
- 時間軸 / $\text{J}$, $\text{T}$：8, 9, c, d / a, b, e, f
- $\text{Observe}$：$H_O=$ {0, 1, 4, 5}
- $\text{Straight}$：$H_S=$ {2, 3, 6, 7}
- $\text{Jab}$：$H_J=$ {8, 9, c, d}
- $\text{Twist}$：$H_T=$ {a, b, e, f}

Hexは住所、同値類が実際に必要な状態、Responsibilityは住所区画を跨がせる差
