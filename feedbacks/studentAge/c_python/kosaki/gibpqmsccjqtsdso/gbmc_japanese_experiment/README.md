# GBMC 日本語言い換え比較実験 v0.1

出典: `261012_ガチで成果物作りたい。.md` の日本語言い換え10組。

## 目的
文章の表現が変化しても、共有される意味条件が維持されるかを調べる。現時点では **人手による意味注釈** であり、GBMCエンジンやLLMによる意味抽出の自動検証ではない。

## ファイル
- `pairs.csv`: 原文、比較する言い換え、共有意味条件、差分、予備判定。
- `compare.py`: CSVを読み込み、判定別件数と各組の共通条件・差分を表示する。

## 実行
```
python compare.py
```

## GBMCとの対応（設計案）
- Input: 日本語の文章
- Buffer/Pool: 意味候補・未確定情報の保持
- Coherence: 元文と言い換えの条件整合性を検査
- Hold: 条件の対応が未確定なら判定を保留
- Output: 共通条件、差分、判定と根拠

これは **GBMCを使った実装の仕様案** であり、既存v0.8の音楽用Room遷移をそのまま実行した結果ではない。

## 次の検証
文ごとに主語・述語・条件・量化・モダリティ（可能性／断定）を機械抽出し、人手注釈と比較する。次に日本語→英語→Pythonなどに拡張する。
