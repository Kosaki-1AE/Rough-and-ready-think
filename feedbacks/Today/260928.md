**パーセプトロン** → **多層パーセプトロン（MLP）** → **ニューラルネットワーク** → **誤差逆伝播** → **深層学習** → **CNN / RNN / LSTM** → **Attention** → **Transformer** → **LLM**
1. パーセプトロン
	- 入力を重み付きで足して、判定する。
	- 「どの入力をどれだけ重く見るか」

2. 多層パーセプトロン（MLP） -> ニューラルネットワーク
	- パーセプトロンを何層も繋ぐ
	- 「単純な意思決定器を組み合わせれば、複雑な判断ができる」

3. 誤差逆伝播
	- 出力ミスったらその誤差分を各重みへ責任を逆配分する
	- 「この間違い、どの重みがどれくらい悪かった？」

4. 深層学習
	- 層をめちゃくちゃ深くする
	- 低層：単純特徴 / 中層：部分構造 / 高層：抽象概念

5. CNN / RNN / LSTM / GRU
	- CNN
		- 画像用に特化
		- 局所的な特徴を拾う
	- RNN
		- 時間順序を持つデータ用
		- 「前の状態を次へ渡す」
	- LSTM / GRU
		- RNNの「昔の情報を忘れやすい」問題を改善
		- 「Memoryを明示的に管理するNN」

6. Attention
	- 今の判断に重要な場所を重点的に見る
	- Query：何を探してる？ / Key：何と照合する？ / Value：実際の情報

7. Transformer
	- Attentionを主役にしたモデル
	- $\text{Self-Attention} + \text{FFN}$

8. LLM
	- Transformerを巨大化
	- $P(\text{next token}|\text{context})$
	- 「次に何が来るかを予測し続ける巨大な状態遷移モデル」

```python
import numpy as np


class Perceptron:
    def __init__(self, n_features, learning_rate=0.1):
        self.w = np.zeros(n_features) # 重み
        self.b = 0.0 # バイアス
        self.lr = learning_rate # 学習率
        
    def activation(self, z):
        return 1 if z >= 0 else 0 # 活性化関数（ステップ関数）

    def predict(self, x):
        z = np.dot(self.w, x) + self.b
        return self.activation(z) # 予測

    def train_one(self, x, y): # 1データ分の学習
        y_pred = self.predict(x) # 自己予測
        error = y - y_pred # 誤差
        self.w += self.lr * error * x# 重み更新
        self.b += self.lr * error　# バイアス更新
        return error

    def fit(self, X, y, epochs=10): # データセット全体を学習
        for epoch in range(epochs):
            errors = 0
            
            for xi, yi in zip(X, y):
                error = self.train_one(xi, yi)

                if error != 0:
                    errors += 1

            print(
                f"epoch={epoch + 1}, "
                f"errors={errors}, "
                f"w={self.w}, "
                f"b={self.b}"
            )
```
