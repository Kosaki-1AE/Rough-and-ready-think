#KIT/学習/coding 
一応MacとWindowsの類似点で見れるようにするだけで終わろうかなぁって思いましてな。
Windows の場合は「ping → ip addr → ip route → ufw → ss → nmap → tcpdump → Wireshark」 
⬆️この順っていうことになってんだけどさ。
MacのTerminal でも同様になってるか知りたいのはあるのよなぁ。MacのTerminal(今用いてるマシンがIntelMac Pro15なので、それの最新バージョン、つまりは10年前とか当時の最新バージョンです) の場合になるので....
「ping -c 4 8.8.8.8 → networksetup -listallhardwareports → ipconfig getifaddr en0 → netstat -rn → sudo /usr/libexec/ApplicationFirewall/socketfilterfw -getglobalstate→ lsof -i → nmap → tcpdump → wireshark」

これを比較すりゃいいんかな。Windowsの場合とIntel Macの場合でできるようにして終わりで良い気がするのよね。👈 終われましたw よかったぁぁぁ。
