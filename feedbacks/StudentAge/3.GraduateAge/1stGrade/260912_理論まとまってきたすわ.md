多分こう定義できる：
- 深さの上限 = それ以上メタ化すると、区別を作っていた前提そのものが消える点
- 意味の壁 = 現在の意味生成規則では越えられない境界

んで判別方法これらしいの：
1. 新しい区別が増えない
    一段深くしても、予測できること・区別できることが増えない。
2. 自己参照が始まる
    「ルールを説明するルール」が、自分自身にも適用される。
3. 上位と下位が同型になる
    一番深い構造が、最初に見ていた表面の構造と同じ形になる。

「自由度を誰が決めるか」と「ルールを書き換える権限を誰が持つか」👈この2つかw

1. 区別が同じになったか：最初に「自分／他人」「自由／制約」みたいな区別があって、深く掘った結果、結局また同じ区別が必要になった。
2. 遷移規則が同じになったか：「情報を与える→自由度が変わる→行動が変わる」という構造が、教育・いじめ・ダンス・責任の全部で再登場した。
3. 予測が増えなくなったか：さらに一段メタ化しても、「結局また自由度と遷移の話やん」になった。

一周する理由：ルールを掘っていく操作そのものも、結局ひとつのルールだから

境界の種類もこんだけあるっぽいの：
- 対象範囲：「誰・何に適用するか」
- 時間範囲：「いつからいつまで適用するか」
- 参照範囲：「このルール自身や上位ルールにまで適用するか」

秩序とは、ルールそのものではなく、自由度制御権の配分状態である。
- 支配 = 自由度制御権の集中
- 自治 = 自由度制御権の分散
- 教育 = 自由度制御権の移譲
- 責任 = 自由度制御の結果回収

ここでの担保は「責任の回収可能性」ってことらしいw
- 信用 =「こいつは将来ちゃんと回収するだろう」という期待値
- 担保 =「期待が外れても回収できるもの」
-> 権限と回収能力を釣り合わせる制度 👈これできるんならやってるんよ全員w

回収能力 = ズレを実際に戻せる能力
信用 = 将来も回収できるだろうという予測
担保 = その予測が外れたときにも回収可能性を残す資源
-> 未来の予測誤差があっても責任を回収できるように、使わずに残しておく自由度

自由度を渡す量 = 弟子の自己回収能力 + 師匠が肩代わりできる回収能力 − 安全余白

「壊していい場所が分かる」だけじゃなく、「壊したあと自分で戻せる」 👈これで権限が渡せるようになる

GBMCと繋げるわ。今なら行ける気がする。
大元：set(G) -> hit(B) - /GL >  shoot(M) -> pop(vector(C$_1$ - /DO > C$_2$) -> 責任の矢(Q) - /BO > scalar(S)) -> off(D) - /CM > set(G)....
- set(G)：メモリ確保
- hit(B)：未来をまだ完全には決めないことで保持される、責任回収用の自由度
- GL：責任の整合(自由度へのヒープとでも言いましょうかね)
- shoot(M)：仮の実行(現在ある分の責任での実行。なのでちゃんと実行だけど「仮」と付けてます)こと「保険」生成
- pop(C$_1$)：自分の中の現在の選択肢の整理
- DO：整理後の洗い出し(というか濾過に近い気がする)
- pop(C$_2$)：自分の本音が出揃った中で欲しい選択肢を選択(「本音」の生成)
- 責任の矢(Q)：MとC$_2$の何らかの関係性から場に責任を生成する(差分の可能性が濃厚)
- BO：責任と場の整合の配分比較(的なこと)
- scalar(S)：場だけ見て次の選択肢の候補となるものを推測する
- off(D)：今の時点だとどこの責任までを自分の領域に含めるか決定する
- CM：自分の領域に対してヒープアルゴリズムを用いてメモリとなりそうな部分を洗い出す

こうらしい：
- set(G)：メモリ確保
- hit(B)：未来をまだ完全には決めないことで保持される、責任回収用の自由度
- GL：現在保持しているBの中で、どこまでの失敗を回収可能かを評価する処理
- shoot(M)：Bによってrollbackの可能性が担保された実行
- pop(C$_1$)：自分の中の現在の選択肢の整理
- DO：整理後の洗い出し(というか濾過に近い気がする)
- pop(C$_2$)：自分の本音が出揃った中で欲しい選択肢を選択(「本音」の生成)
- 責任の矢(Q)：MとC$_2$の何らかの関係性から場に責任を生成する(差分の可能性が濃厚)
- BO：責任と場の整合の配分比較(的なこと)
- scalar(S)：場だけ見て次の選択肢の候補となるものを推測する
- off(D)：次ループにおける自己参照範囲の確定
- CM：自分の領域に対してヒープアルゴリズムを用いてメモリとなりそうな部分を洗い出す

これで言う責任ってのが「Cでズレを発見したとき、どこまで戻って回収する権限とBufferを自分が持っているか」ってことになるらしいw
