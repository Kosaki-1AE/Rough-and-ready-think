- GL：G→B→M = 基準に乗る：拍・型・基準に入る
- DO：G→S→Q = 差分を出す：ズラす・遊ぶ・個性を出す
- BO：D周り = 差分が詰まる：力む・詰まる・破綻する
- CM：D→C$_1$/C$_2$ = 差分を回収する：戻す・締める・余韻を作る


Lie括弧がゼロ(可換・アーベル)⇔ 可積分 ⇔ 葉に閉じ込め ⇔ 不変量(上限：GL / 下限：CM) 
Lie括弧が非ゼロ(非可換・非アーベル)⇔ 括弧生成 ⇔ 葉を脱出 ⇔ 個性(上限：DO / 下限：BO)
不変量=アーベル端、個性=非アーベル端、意味の壁=その軸の切り替わり点

- 幾何学的制御にもアーベル/非アーベルがある(ベクトル場が可換に交換するか=Lie括弧がゼロか非ゼロか) = 到達可能性(そこに行けるか)
- 劣リーマンにもある(分布の括弧が閉じるか開くか) = そのコスト(行くのにいくらかかるか)。つまり**制御+計量**。制御理論に距離を足しただけ
- ゲージにもある(U(1)=アーベル、Yang–Mills=非アーベル) = 一周のズレ(ホロノミー)
