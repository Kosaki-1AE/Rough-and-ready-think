#Mine研究 
- 合流性：
同じ出発点から違う経路で進んでも、最終的に同じ所に畳める性質。「経路(個性)はバラける、着地点(不変量・責任)は一個」がこれそのもの。「順不同でいい=合流する」「方向がある=合流しない(経路依存)」で割れる。

- Newmanの補題(Newman's Lemma)：
「局所合流(操作がバッティングした場面だけ合流する)＋停止する」が言えれば、全体の合流が自動で従う、という定理。無限の経路を確かめなくていい根拠。「自分の許す範囲で往復」「時間的制約」が停止条件にあたる。

- 臨界対(Critical Pairs)：
2つの操作が同じ状態で衝突する場面のこと。局所合流は、この臨界対が再合流するかを見るだけで確かめられる。4権限なら6ペア。

- Knuth-Bendix completion：
合流してない時に、規則を足すか向きを付けるかして合流させようとするアルゴリズム。君の「順々にするための方向があるってことか」の"方向"(=簡約順序/項順序)を自動で導出する装置。君の2択(順不同/方向あり)がこれの2つの出力に対応。

- 正規形(Normal Form)：
これ以上簡約できない最終状態。「責任」に対応。合流＋停止が言えると、正規形が一意に決まる。

- Union-Find / 経路圧縮(Path Compression)：
「経路圧縮が為される/圧縮前の経路があるはず」に対応するデータ構造とその最適化技法。

- Version space(版空間)
複数の仮説を残したまま、観測と整合する候補だけを絞り込んでいく機械学習の枠組み。「確率デバッグ(複数仮説を残して整合性で絞る)」「決まってない候補の集合」がこれ。合流を確かめる"前"の探索段階にあたる。

俺の理論に接続すると....
Version space(版空間) → 臨界対(Critical Pairs) → Newmanの補題 → 合流性 / Confluence → Knuth-Bendix completion → 正規形(Normal Form) → Union-Find / 経路圧縮

- 型が変わる＝遷移。GL→CM(入口の固着が解けて関わり出す)とか、CM→BO(関わり続けて踏み抜く)とか。
- どの遷移が起きるか＝今日の C(遷移)とR(変換)、そして配分・意味の壁が引き金。
- 遷移順に方向があるか／順不同か＝合流性 / 臨界対。例えば「GL→DO」と「GL→CM」みたいに、同じ入口から分岐する点＝臨界対。
- 「傾向として見る」＝遷移確率。どの状態からどの状態へ行きやすいか＝確率の雲
