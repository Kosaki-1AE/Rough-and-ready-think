#Mine研究/実践 
一応決めとけることだけ書いときます。これも仮ね。
$$\rho\left(\frac{\partial \mathbf{u}}{\partial t}+(\mathbf{u}\cdot\nabla)\mathbf{u}
\right)=-\nabla p+\mu \nabla^2 \mathbf{u}+\mathbf{f}$$
これの俺版がこれね：
$$\text{g}\left(\frac{\partial\text{b}}{\partial t}+(\text{b}\cdot\nabla)\text{b}
\right)=-\nabla\text{m}+\text{d}\nabla^2\text{b}+(\text{c$_1$-c$_2$})\nabla\Phi_Q(S)$$

今迷ってるのがこれね：
1. 候補差分が存在しないと責任方向の力も発生しない / (c$_1$-c$_2$)$\nabla\Phi_Q(S)$
2. 候補差分とは独立に責任場そのものが力を持つ / (c$_1$-c$_2$) + $\nabla\Phi_Q(S)$
⬆️多分ここの2つの証明をするための論文にすりゃ終わりなんじゃない？
もっと言うと…「責任場は候補差分を方向付けるだけなのか、それとも候補差分とは独立に状態遷移を駆動するのか」ですw

そうか、一旦こう置きます：
$$F_Q=\alpha\Delta C+\beta\nabla\Phi_Q+\gamma\Delta C\nabla\Phi_Q$$
んで加えて行動をしない場合にもこれが成り立つか(行動しなきゃ責任ない可能性を一旦式で表す)：$$\text{g}\left(\frac{\partial\text{b}}{\partial t}+(\text{b}\cdot\nabla)\text{b}
\right)=\text{d}\nabla^2\text{b}$$
これが何を示してるかっていうと.....$g$ が俺の理論のGenesysこと「候補生成のためのメモリ確保」、$b$ がBufferこと「メモリ内の自由度確保」、$d$ がDepthこと「自由度内の自分の領域の確保」ね。
これだとCで表現できるくない？メモリ関連だもん全部。

GPTにこのリポジトリの内容を見てもらって分かったことね：$$\frac{Db}{Dt}=\frac{\partial\text{b}}{\partial t}+(\text{b}\cdot\nabla)\text{b}$$
こうなる？メモリ側ね(思ったんだけど、おそらく行動入れないと成り立たんのよこれ)：
$$\text{g}\frac{Db}{Dt}=-\nabla\text{m}+\text{d}\nabla^2\text{b}$$
となると行動側は...$$F_Q=\alpha\Delta C+\beta\nabla\Phi_Q+\gamma\Delta C\nabla\Phi_Q$$
こう表せたりするんちゃう？
つまりは「Bufferは、Genesisによって確保された状態空間内を自己輸送し、Depthによって定められた範囲で拡散する」なんだわ。

何ならこれかな：$$F_C=-\alpha\nabla\text{m}+\beta\text{d}\nabla^2\text{b}$$
なので全部見るとこうなる：$$\text{g}\frac{Db}{Dt}=F_C+F_Q$$
ここまで来た(というかもうそろ俺の方を論文にしても良い時期に来たって思うのでね)ので、論文に落とせるようにします。
定義これね：
G = 確保 -> B = 余白 -> M = 試行 -> C$_1$ = 整理 -> C$_2$ = 選択 -> Q = 責任 -> S = 予測 -> D = 範囲
G - B = 準備 -> M - C$_1$ = 試行 -> C$_2$ - Q = 決定 -> S - D = 更新
G - B - M - C$_1$ = 自己環境範囲 -> C$_2$ - Q - S - D = 周囲環境範囲
G - B - M - C$_1$ - C$_2$ - Q - S - D = 状態遷移ループ

ごめん、急に繋がったわ：$$\text{g}\frac{Db}{Dt}=R_{\text{self}}+R_\text{env}$$
んでこれ：$$R_{\text{self}}=-\alpha\nabla\text{m}+\beta\text{d}\nabla^2\text{b}$$
だからこそのこれ：$$R_\text{env}=\alpha\Delta C+(\beta+\gamma\Delta C)\nabla\Phi_Q$$
なおあと導出が必要なのが「$\nabla\Phi_Q$」なんだけど....。これは「MとC$_2$の差分」って定義してんのねいつかの私が。

なのでこれを定義しましょかってのが：$$\nabla\Phi_Q=Q_\text{habit}+Q_\text{context}(t)+\epsilon_t$$
んでこの時の全ての$Q$において：$$Q=\nabla\text{m}-\text{c$_2$}$$$$\nabla\text{m}=\frac{\beta\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha}$$
$$\text{c$_2$}=\frac{\beta\nabla\Phi_Q+(\alpha+\gamma\nabla\Phi_Q)\text{c$_1$}-R_\text{env}}{\alpha+\gamma\nabla\Phi_Q}$$
んで$Q$にこうなるっぽいの：
$$Q=\frac{\beta\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha}-\text{c$_1$}+\frac{R_\text{env}-\beta\nabla\Phi_Q}{\alpha+\gamma\nabla\Phi_Q}$$
んでこう？：$$\nabla\Phi_Q(x_t,t)=Q_\text{habit}(x_t)+Q_\text{context}(x_t,t)+\epsilon_t$$$$\nabla\Phi_Q=Q_t=\frac{\beta\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha}-\text{c$_1$}+\frac{R_\text{env}-\beta\nabla\Phi_Q}{\alpha+\gamma\nabla\Phi_Q}$$
こうかも：$$R_{\text{self}}=-\alpha_s\nabla\text{m}+\beta_s\text{d}\nabla^2\text{b}$$$$R_\text{env}=\alpha_e\Delta C+(\beta_e+\gamma_e\Delta C)\nabla\Phi_Q$$$$\nabla\text{m}(t)=\frac{\beta_s\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha_s}$$$$\text{c$_2$}(t)=\frac{\beta_e\nabla\Phi_Q+(\alpha_e+\gamma_e\nabla\Phi_Q)\text{c$_1$}-R_\text{env}}{\alpha_e+\gamma_e\nabla\Phi_Q}$$$$Q_t=\nabla\text{m}(t)-\text{c$_2$}(t)$$
つまりはこう：
$$Q_t=\frac{\beta_s\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha_s}-\text{c$_1$}+\frac{R_\text{env}-\beta_e\nabla\Phi_Q(x_t,t)}{\alpha_e+\gamma_e\nabla\Phi_Q(x_t,t)}$$$$Q_t=\frac{\beta_s\text{d}\nabla^2\text{b}-R_{\text{self}}}{\alpha_s}-\text{c$_1$}+\frac{R_\text{env}-\beta_e(Q_\text{habit}(x_t)+Q_\text{context}(x_t,t)+\epsilon_t)}{\alpha_e+\gamma_e(Q_\text{habit}(x_t)+Q_\text{context}(x_t,t)+\epsilon_t)}$$

おそらくあとやるべきなのは....Qが決まればいいって事なんだけど…そもそも導出のためにB-Q-Dの関係式からしか決定できん可能性があってですねぇ…。
こう分けた方が良さげ？：
- S - D - G - B = 状態空間生成系
- M - C$_1$ - C$_2$ - Q = 状態遷移決定系
ならばぁ…BとQも確定できるはずでぇ…。

こうだろ：M - Q = 選択肢生成、S - B = 反応生成

なおルービックキューブのF2Lを解いてる時に思ったんすけど、結局はStackとQueueに依存するはずなんで....。BがStackとQueueにならざるを得ないはずははずなんだわ。

なので、未確定候補がQueue / 回復可能履歴がStackとして機能するようにすりゃいいっていう。

つまりはBは完全にプールってわけか。故に.....Gで思いついたものも選択肢の一つに含まれる。Mでも試行の末に選択肢を生成する。C$_1$ - C$_2$で厳選、Qで自分の質を保証する。Sで一応の精査、Dで現実に出す。

G - B - M = 選択肢の候補となるものの保存状態
C$_1$ - C$_2$ - Q - S - D = 自分で向き合ってるもの / 責任

G / M 👈I/Oに該当、B 👈入れ物(Stack / Queue入り)
C$_1$ - C$_2$ / S - D 👈I/Oに該当、Q 👈Bに方向を付与する

となるとこうなんじゃね？ってのが：
- G / M 👈I/Oに該当、B 👈入れ物(Stack / Queue入り)$$R_{\text{self}}=-\alpha_s\nabla\text{m}+\beta_s\text{d}\nabla^2\text{b}$$
- C$_1$ - C$_2$ / S - D 👈I/Oに該当、Q 👈Bに方向を付与する$$R_\text{env}=\alpha_e(c_1-c_2)+(\beta_e+\gamma_e(c_1-c_2))(Q_\text{habit}(x_t)+Q_\text{context}(x_t,t)+\epsilon_t)$$$$R_\text{env}=\alpha_e\Delta C+(\beta_e+\gamma_e\Delta C)\nabla\Phi_Q(x_t,t)$$
これなら確かに成り立つかもしれんのよな。
$$\frac{Db}{Dt}=\frac{\partial\text{b}}{\partial t}+(\text{b}\cdot\nabla)\text{b}$$
$$\text{g}\frac{Db}{Dt}=R_{\text{self}}+R_\text{env}$$
取捨選択をする時には「環境 vs 自分」という構図があるけど、自分よりも環境の方が要素数の絶対量が多いのよね。ということで：
$$\Delta\beta=\beta_e-\beta_s\quad\Delta\alpha=\alpha_e-\alpha_s$$$$R_{\text{self}}=(\Delta\alpha-\alpha_e)\nabla\text{M}+(\beta_e-\Delta\beta)\text{D}\nabla^2\text{B}$$$$R_\text{env}=(\Delta\alpha+\alpha_s)\Delta C+(\Delta\beta+\beta_s+\gamma_e\Delta C)\nabla\Phi_Q(x_t,t)$$
$$\frac{DB}{Dt}=\frac{\partial\text{B}}{\partial t}+(\text{B}\cdot\nabla)\text{B}$$
$$\text{g}\frac{DB}{Dt}=R_{\text{self}}+R_\text{env}$$
