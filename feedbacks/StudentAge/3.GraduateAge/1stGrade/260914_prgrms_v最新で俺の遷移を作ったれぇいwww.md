#Mine研究 
ちな俺にとっての責任の定義ですが…「場を開く -> 閉じる or 同じくらいの責任を持つ人に託す」ですw
んで責任を背負う(というか背負わされるが大きいのかな)場合、絶対に時間経過を待ってくださいませ。じゃないとその場で押しつぶされるからね。

形式的権限と実質的権限のズレ 👈これらしいww

ここまでに作ってきたものがこいつダァ：
0. scalar(S)-off-CM-：責任範囲を作る / 0->3 / 論理 / 01 / mbti：E / I
1. set(G)-hit-GL-：自由度を用意する / 1->0 / 概算 / 10 / mbti：S / N
2. shoot(M)-pop-DO-：世界に試す / 2->1 / 意味認識 / 11 / mbti：J / P
3. pop(C$_2$)-責任の矢-BO-：意味と責任を確定する / 3->2 / 対象外 / 00 / mbti：T / F

何を作るべきかを現場で決められるか(つまりはFDE適性ってやつすね)
- 状態の担保：今どこにいるか分かる
* 履歴の担保：なぜここに来たか辿れる
* 境界の担保：何を触ってよくて何が危険か分かる
* 回収の担保：失敗時にどこまで戻せるか分かる
* 責任の担保：誰が最終的に閉じるか分かる

理解 + 履歴 + 回収手段 = 権限
- 担保＝回収可能性
- 保証＝他者による責任引受
- 信用＝過去履歴から見た将来の回収期待

最上位をCOBOL-中間をPython-最下位をC的にできるようにしよう 👈これだァァァ
