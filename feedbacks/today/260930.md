なんか思ったけど、粘性＝歴史の長さってことにしていいんじゃ？

- 1枚目 = 保険 = ジャブ = y_backup
- 2枚目 = 本音 = ストレート = y_main

昨日こんなの組んだんすよ：
- x = (x_main, x_backup) / 00-01-10-11
- x_main = (x_m_main, x_b_main) 👈それぞれ1/4
- x_backup = (x_m_backup, x_b_backup) 👈 それぞれ1/4
- x_main < x_backup(権限上こうなる / 1 < 3)
- $\neg$ x_main = x_backup
- $\neg$ x_backup =  x_main $\lor$ backrooms
- y_backup = x_backup $\land$ $\neg$ backrooms

ちな内容ね？：
- x_main = 本命候補の入力状態
- x_backup = 保険候補の入力状態(0/1)
- x_m_main = 本命候補の中での本命候補の入力状態
- x_b_main = 保険候補の中での本命候補の入力状態
- x_m_backup = x_b_backup = 候補集合
- y_main = 本命候補が条件を満たしたか
- y_backup = 保険候補が条件を満たしたか
- w_main / w_backup = 各候補に対する責任重み
- b_main / b_backup = 各候補を採用するための基準線
- error_main / error_backup = 各候補の予測と結果のズレ

x_mainとx_backupがそれぞれ要素の中から1/4で選ぶんだけど、責任によって一番重くなったやつは抜くのね。だから実質1/3。ここでの選択肢の量＝選択する速度(責任加味してるのでほぼこれで間違いないと思われる)になる可能性高くてな。
