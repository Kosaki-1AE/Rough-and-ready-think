命題の成立範囲を拡張するときには、その拡張を正当化する根拠が必要である。その根拠を与えられない境界が、壁として現れる 👈これ言えるっぽいぞ？w

リーマン予想が証明できた的なことを言われたやんすかw あれを俺の理論で説明できないかなぁ的なことを考えてたんだけどさぁ
- 零点がどこにあるか -> 素数に関する量がどこまで増加できるか
- 4壁によって既存手法以上の保留が実現できたかについては、BOで保留する
- リーマン予想 -> 零点の存在範囲を制限 -> 素数の分布に関する不等式 -> 代数的な構造に変換 -> 必要な不等式を導出

なお俺の感覚としてこういうのが成り立つと思うってのが：GL < DO < BO < CM
ここでの軸となるのが「自由度」ですね。自由度の逆は制限なのでね。制限するかしないかのみなので。
- 条件の同一性 -> 定義の同一性 👈定義を確定するには条件を確定させなあかんのは自明なのでこれも自明
- 定義の同一性 -> 責任上の同一性 👈定義が定義できてしまえば、どこまで回答者だったり提供者だったりが自由に発想できるかが確定できる、故に責任上の同一性は担保できるはず
- 責任上の同一性 -> 意味付けの同一性 👈ある程度の道順まで確定すりゃ責任を取れるようになる $=$ 意味付けとしてのラベルの探索を許可できるほどには余裕が出てくるため、同一性を担保できると踏んだ
- 意味付けの同一性 -> 条件の同一性 👈これは自明。一つラベル付けできたら条件も確定できるため

ダンスと合わせてみると：
- 置く / ~GL
- 当てる / ~DO
- 外す / ~BO
- 強制停止 / ~CM
