中の意味合いね：
- Room：可変長状態空間 / 因果・機能的部分空間＝同じ遷移に責任を持つ要素集合(functional subspace) / 系全体ではなく、ある主体・作用単位が現在扱える局所状態空間(backroomsの扱い)
- hex：Room内の局所アドレス / 「今このRoomでは何をしているか」のタグ(local state code)
- O・S・J・T：そこからの遷移様式
- 4bit：Room内部の局所状態指定
