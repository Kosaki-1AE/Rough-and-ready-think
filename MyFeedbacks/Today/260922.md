ナビエ・ストークス方程式：
$$\rho\left(\frac{\partial \mathbf{u}}{\partial t}+\mathbf{u}\cdot\nabla)\mathbf{u}
\right)=-\nabla p+\mu \nabla^2 \mathbf{u}+\mathbf{f}$$
* $\rho$：密度 
* $\mathbf{u}$：速度場
* $\frac{\partial \mathbf{u}}{\partial t}$：時間変化
* $(\mathbf{u}\cdot\nabla)\mathbf{u}$：移流、自分の流れによって流れが運ばれる項
* $p$：圧力
* $\mu$：粘性係数
* $\mu\nabla^2\mathbf{u}$：粘性による拡散
* $\mathbf{f}$：外力

ここからこうした：
* $\rho$：密度 = set
* $\mathbf{u}$：速度場 = hit
* $p$：圧力 = shoot
* $\mu$：粘性係数 = off
* $\mathbf{f}$：外力 = pop
