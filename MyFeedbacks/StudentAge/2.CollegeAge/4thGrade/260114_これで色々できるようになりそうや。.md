#Mine研究 
構造ってどう作るんや？
① 生きる：履歴作りで必須
② 失敗する：バグを作るきっかけ、変わるきっかけそのもの
③ 繰り返す：失敗を成功に変えるためには必要でしょ
④ パターンに気づく：要は公式がこれなわけで。もっというと数学これやん大体
⑤ 名前をつける：ラベル化なんだけどさ。GPTとかを作るときのベクトル作りにね。
⑥ 共有する：全体で同じような「テーマ」を作るのがここになるはず
⑦ 固定化される：テーマの出し方そのものすら分かってくるとここになります(再利用可能条件が分かると嬉しいのよね)

即興ダンスの場合は➆⇨②に行く必要があるらしいのね。

履歴⇨バグ⇨成功体験⇨公式⇨ラベリング⇨テーマ化⇨出し方
1. 履歴⇨バグ⇨成功体験：ライフゲーム
2. 成功体験⇨公式⇨ラベリング：マインスイーパ
3. ラベリング⇨テーマ化：GPT問い
4. テーマ化⇨出し方：表現出力

多分これを使うんだろうなぁってのが⇩
$$\Delta t := t_{n+1}-t_n \quad なので$$$$x_{n+1}=f(x_n)=\frac{dx_n}{dt}=x_n+f(x_n)\Delta t$$
$$\begin{cases}x_{n+1}=x_n+f_n(x_n)\Delta t \\ f_{n+1}=\Phi(f_n,x_n)\end{cases}$$
$$\begin{cases}f_n(x_n)=\frac{x_{n+1}-x_n}{t_{n+1}-t_n}\\ \frac{f_{n+1}-f_n}{t_{n+1}-t_n}=\psi(f_{n},x_{n},t_{n})\end{cases}$$

これが「B→MのC→G」と「M→CのC→G」の2つの見え方の違いなんだけどさ。上の方が前者、下の方が後者になるんすけど。
これを見ながら調整できるものがあると嬉しいんだろうなぁって。
んでもって。数式でやるというよりも構造でやる方が嬉しいんだろうなぁ。

んで今思ったんだけどさ。とりあえず全部既存理論で言い換えよう。その方が安定するんでね。

| 君の構造要素                | 対応する理論・論文                                                      | 根拠                                      |
| --------------------- | -------------------------------------------------------------- | --------------------------------------- |
| Candidate Options     | **Affordance Competition (Cisek)**                             | 行動は「逐次生成→競合→選択」される。脳は常に複数の可能行動を並列保持している |
| Genesys phase（生成）     | **DanceGenのIdeation段階 / Language Modeling by Language Models** | 振付は非線形・再帰的で、最初は大量の素材生成が行われる             |
| Buffer phase（文脈フィルタ）  | **Temporal Context Model (Howard & Kahana)**                   | 文脈は「ドリフト」しながら保持・更新され、次の選択に影響            |
| Motion phase（実行）      | **Affordance Competition**                                     | 行動は逐次的に指定され、選択と実行が同時進行                  |
| Coherence phase（整合評価） | **PAC分析 / 舞踊する身体**                                             | 身体の熟達は自己との整合（心身一如）として評価される              |
| Kukikan（空気感）          | **分散的文脈表現（TCM）**                                               | 文脈はベクトル空間上の状態として表現される                   |
| Responsibility Field  | **Affordance Competition**                                     | 意味は「表象」ではなく「相互作用の場」として成立                |
| Temporary Selection   | **Pruning as a Game**                                          | 競合の中で“参加度”が落ちるものが自然消滅する                 |
| Candidate Options n+1 | **Pruning理論**                                                  | 構造は固定でなく、競合と淘汰で次世代が生まれる                 |

まずは俺の理論の軽い流れ言うやん、その後に既存の理論での言い換えをするやん。そんで既存の理論の実装面をもうちょいカバーできるものが欲しいかもしれんな。
